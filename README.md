# 🛒 QuickBasket Nepal

A modern **full-stack grocery delivery web application** built with the **PERN Stack (PostgreSQL, Express.js, React, Node.js)**. QuickBasket Nepal allows customers to browse groceries, manage their cart, place orders securely, and provides administrators with tools to manage products, categories, users, and orders.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/codewithrabeen/QuickBasket.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file inside the backend.

```env
PORT=
DATABASE_URL=
JWT_SECRET=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

CLOUDINARY_NAME=
CLOUDINARY_KEY=
CLOUDINARY_SECRET=

FRONTEND_URL=
```
